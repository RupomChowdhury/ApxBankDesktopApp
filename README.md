APXBank is a modern, responsive Windows desktop banking application built with C#, .NET 9, and WPF following clean MVVM architecture. Designed with a sleek, dark Obsidian FinTech aesthetic, it features real-time multi-account management, interactive virtual debit card controls, seamless funds transfer, a live searchable ledger, and spending analytics.
